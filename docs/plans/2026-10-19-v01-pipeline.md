# Clickstream v0.1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. In this environment, continue directly under the user's explicit implementation request using the available execution workflow.

**Goal:** Produce deterministic clickstream events, ingest through Managed Flink into Glue-backed Iceberg, reconcile exact business keys with Athena, and clean up the demonstration.

**Architecture:** Python generates NDJSON and an immutable manifest. A Java Flink 1.20 application reads Kinesis with TRIM_HORIZON, validates/maps events and commits an Iceberg v2 table through checkpoints using GlueCatalog and S3FileIO. Athena engine 3 reads the table and Python compares full event content, multiplicities and business keys with the manifest.

**Tech Stack:** Python 3.11+, boto3, Java 11, Flink 1.20, Kinesis connector 5.0.0-1.20, Iceberg 1.10.0, Terraform AWS provider 6.67.0, Athena engine 3.

## Design decisions

- Use a Java DataStream job: explicit connector and checkpoint configuration with a compiled, testable artifact. A SQL-only job is shorter but adds SQL planner packaging; PyFlink adds Python runtime packaging. Keep the producer and reconciliation in Python.
- Baseline is append-only with no deliberately duplicated inputs. Kinesis API timeouts can produce ambiguous delivery; do not claim producer exactly-once. Retry only explicit per-record throttling failures, fail on ambiguous transport errors, and detect duplicate keys during reconciliation. v0.2 adds replay/deduplication experiments.
- Every run has an explicit run_id; identical seed/base time/run_id/journey count generate byte-identical files. A rerun into the same append-only table is not idempotent: use a fresh run_id for a new ingestion.
- Integer cents and UTC strings avoid floating-point money and timezone ambiguity. Event IDs are deterministic UUIDv5 business keys. The manifest contains the complete small demo dataset hash and expected rows.
- No generic S3 expiration on Iceberg data/metadata. Keep raw uploads and Athena results separately scoped. Never delete files under an active Iceberg table as cleanup.
- Pipeline resources are opt-in. Default remains the verified skeleton. Bound application parallelism to one, disable autoscaling and snapshots for this disposable demo, cap Athena scans, stop the app before teardown and purge only the confirmed demo bucket.

## Task 1: deterministic producer and reconciliation

Create `src/clickstream/events.py`, `publish.py`, `reconcile.py`, `cli.py`, `pyproject.toml`, and `tests/test_*.py`.

Tests: byte stability and golden digest, funnel parent relationships, unique event keys, invalid parameters, explicit partial Kinesis retries, ambiguous errors propagated, and reconciliation rejecting missing/extra/duplicate/corrupt rows.

Run: `python -m unittest discover -s tests -v`. Generate a fixed 500-journey dataset and preserve its manifest as demonstration evidence.

## Task 2: Flink artifact

Create `flink/pom.xml`, `ClickstreamJob.java`, event-mapping tests. Build shaded Java 11 artifact with Flink dependencies provided, Kinesis connector, Iceberg runtime and AWS bundle included. Use GlueCatalog optimistic locking, Iceberg v2, checkpoint commits and stable operator UIDs. Validate malformed events fail the job rather than silently disappear.

Run: `mvn -f flink/pom.xml verify`; inspect JAR entrypoint and dependency services. No unverified JAR is deployed.

## Task 3: infrastructure and IAM

Add opt-in `infra/pipeline.tf`, variables/outputs and mocked tests; modify lifecycle rules to exclude Iceberg content. Add versioned/checksummed JAR upload, Flink service role with fixed boundary, Managed Flink app, log stream, Athena workgroup with 10 MiB query scan cap. CI validates Python/Java and both Terraform roots.

Generate deployment policies from real or isolated offline Terraform plan JSON using `DISABLE_IAM_POLICY_AUTOPILOT_TELEMETRY=true uvx iam-policy-autopilot@latest generate-policies PLAN.json --region us-west-2 --account 933214686590 --resource-cutoff 100 --pretty`. Review runtime SDK policies and exact resource scopes separately. Prepare administrator boundary/operator policy corrections, with no self-modification grant to the operator. Only apply expanded access after concrete review and required confirmation.

## Task 4: bounded live demonstration

Validate current AWS credentials; review live Terraform plan and concrete cost/runtime scope. Deploy only after authorization covers the actual new application and expanded IAM. Start app, await RUNNING, publish one small run, wait for checkpoint commits, query complete run rows via Athena and reconcile exact data. Capture query IDs, scanned bytes, manifest hash, row counts, key differences and app status. Fail rather than claim success if counts/keys diverge.

## Task 5: delivery and cleanup

Document commands, limitations, architecture, IAM and a 3-minute demo script; capture real evidence/video where supported. Stop Flink, verify READY, delete the named demo Iceberg table and only explicitly confirmed demo objects, then apply a reviewed destroy plan. Verify resource absence and empty main state while retaining bootstrap state storage. Never mark cloud acceptance from mocks or compilation.
